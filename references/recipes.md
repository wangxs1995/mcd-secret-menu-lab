# 隐藏吃法图鉴（供 Agent 模式 B 参考）

> 由 src/recipes.mjs 生成。所有原料均为麦当劳真实在售餐品；运行时必须用 query-meals 校验可得性，菜单里没有的餐品不得出现在方案中。

## 改造机制

- **蘸**（dip）
- **夹**（stack）
- **倒**（pour）
- **摇**（shake）
- **冰火**（ice）
- **组合**（combo）

## 配方

### 🍟❄️ 冰雪薯条（`fries-float`）

- 一句话：咸与甜的第一次握手
- 原料：薯条 + 圆筒冰淇淋
- 菜单匹配关键词：薯条；圆筒冰淇淋 / 圆筒
- 步骤：1. 点一份现炸薯条和一个圆筒冰淇淋　2. 捏住薯条根部，旋转蘸取冰淇淋　3. 趁冰淇淋没化，三秒内入口
- 难度：新手友好 · 场景：下午茶/夜宵 · 标签：咸甜永动机、全网经典、好拍
- 老饕提示：薯条要现炸的，冰淇淋用圆筒比新地更好蘸。

### 🥤⛷️ 可乐浮雪（`cola-float`）

- 一句话：五块钱的麦乐酷平替
- 原料：可乐 + 圆筒冰淇淋
- 菜单匹配关键词：可乐；圆筒冰淇淋 / 圆筒
- 步骤：1. 先喝两口可乐腾出空间　2. 把整个圆筒倒扣进可乐里　3. 用吸管戳碎搅匀，得到一杯浮雪
- 难度：新手友好 · 场景：下午茶/正餐 · 标签：平替魔法、冰爽、好拍
- 老饕提示：先喝两口再放圆筒，不然一定会溢出来。

### 🍔🍗 牛鸡双吉塔（`mega-stack`）

- 一句话：一口咬穿两个汉堡
- 原料：双层吉士汉堡 + 麦香鸡
- 菜单匹配关键词：双层吉士汉堡 / 双层吉士 / 双吉；麦香鸡
- 步骤：1. 把麦香鸡整个夹进双吉中间（或反过来）　2. 轻轻压扁一点更稳　3. 双手拿稳，大口咬下去
- 难度：进阶玩家 · 场景：正餐/夜宵 · 标签：硬核组合、蛋白质炸弹、饱腹
- 老饕提示：先吃掉四分之一再合体，不然真的会散架。

### 🍔🧨 鸡块夹击堡（`nugget-stack`）

- 一句话：给汉堡加装弹药
- 原料：双层吉士汉堡 + 麦乐鸡
- 菜单匹配关键词：双层吉士汉堡 / 双层吉士 / 双吉；麦乐鸡
- 步骤：1. 打开双吉的上层面包　2. 鸡块蘸好随附的甜酸酱，平铺进去　3. 盖上面包压一压，一口咬到底
- 难度：进阶玩家 · 场景：正餐 · 标签：加量流、饱腹、进阶
- 老饕提示：鸡块先蘸酱再夹，防滑又入味。

### 🍔🍟 薯条夹击堡（`fries-burger`）

- 一句话：把快乐夹进面包里
- 原料：巨无霸 + 薯条
- 菜单匹配关键词：巨无霸；薯条
- 步骤：1. 打开巨无霸的顶层　2. 塞入一把薯条（蘸不蘸酱随你）　3. 盖上盖子，趁薯条还脆咬下去
- 难度：新手友好 · 场景：正餐/夜宵 · 标签：全网经典、碳水叠碳水、新手友好
- 老饕提示：别塞太多，不然面包合不上。

### 🥧🔥 冰火菠萝派（`pie-alamode`）

- 一句话：三分钟搭一个甜品台
- 原料：派（选菠萝口味） + 圆筒冰淇淋
- 菜单匹配关键词：菠萝派 / 派；圆筒冰淇淋 / 圆筒
- 步骤：1. 把热菠萝派掰成两半　2. 把圆筒冰淇淋扣在派上　3. 等 10 秒，冰火交界处口感正好
- 难度：新手友好 · 场景：下午茶 · 标签：冰火两重天、甜品控、好拍
- 老饕提示：香芋派也通用，菠萝派酸甜更搭。

### ☕🍦 鲜萃阿芙佳朵（`affogato`）

- 一句话：比官方阿芙佳朵更大杯的 DIY 版
- 原料：鲜萃咖啡 + 圆筒冰淇淋
- 菜单匹配关键词：鲜萃咖啡 / 鲜萃；圆筒冰淇淋 / 圆筒
- 步骤：1. 点一杯鲜萃咖啡和一个圆筒　2. 把圆筒的冰淇淋刮进咖啡杯（或直接把咖啡浇上去）　3. 等冰淇淋边缘微微融化，勺子挖着吃
- 难度：新手友好 · 场景：下午茶 · 标签：高级感、甜品控、麦咖啡周边
- 老饕提示：想要更浓就换浓缩咖啡，想要更甜就换新地。

### 🍟🎵 酸甜摇摇薯（`shake-fries`）

- 一句话：不用摇摇粉也能摇
- 原料：薯条 + 麦乐鸡
- 菜单匹配关键词：薯条；麦乐鸡
- 步骤：1. 点薯条 + 麦乐鸡，多要一盒甜酸酱和番茄酱　2. 把薯条和酱倒进干净的纸袋（或空盒）　3. 摇到每根薯条都裹上酱，趁脆吃
- 难度：新手友好 · 场景：下午茶/夜宵 · 标签：仪式感、重口味、好拍
- 老饕提示：用纸袋摇更均匀，摇完立刻吃。

### 🌅🍳 薯饼夹击堡（`hashbrown-stack`）

- 一句话：早八人的加装包
- 原料：猪柳蛋麦满分 + 脆薯饼
- 菜单匹配关键词：猪柳蛋麦满分；脆薯饼 / 薯饼
- 步骤：1. 打开麦满分　2. 把薯饼夹进肉饼下面　3. 合上，配豆浆或咖啡，早八回魂
- 难度：新手友好 · 场景：早餐 · 标签：早餐限定、加量流、早八回魂
- 老饕提示：薯饼要现炸的，软了就没灵魂。

### 🌅🥖 豆浆泡油条（`soy-youtiao`）

- 一句话：中式早点的麦记解法
- 原料：脆香油条 + 优品豆浆 + 麦咖啡美式
- 菜单匹配关键词：脆香油条 / 油条；优品豆浆 / 豆浆；美式
- 步骤：1. 油条掰成小段　2. 泡进热豆浆三秒（别泡软）　3. 配一杯美式，早八回魂套餐完成
- 难度：新手友好 · 场景：早餐 · 标签：早餐限定、中式混搭、早八回魂
- 老饕提示：三秒是黄金时间，久了就塌了。

### 🍗🍧 勇者鸡块（`brave-nugget`）

- 一句话：甜咸党的终极试炼
- 原料：麦乐鸡 + 新地（选草莓）
- 菜单匹配关键词：麦乐鸡；新地
- 步骤：1. 点一份麦乐鸡和一杯草莓新地　2. 鸡块蘸新地　3. 吃完的算你狠，拍照发群算你赢
- 难度：地狱试炼 · 场景：下午茶/夜宵 · 标签：地狱试炼、咸甜永动机、挑战
- 老饕提示：推荐草莓新地，酸甜口更搭；朱古力味是更深的深渊。

### 💰✨ 1+1 魔法组合（`yijia-yi`）

- 一句话：两套随心配拼出一个四件套
- 原料：随心配 1+1 ×2
- 菜单匹配关键词：精选超值随心配 / 随心配 / 1+1
- 步骤：1. 第一套随心配：主食选汉堡，小食选薯条　2. 第二套随心配：主食选麦乐鸡，饮品选可乐　3. 两套组合约等于一个四件套，钱包友好
- 难度：新手友好 · 场景：正餐/夜宵 · 标签：省钱流、学生党、组合学
- 老饕提示：可选餐品以门店随心配菜单为准，下单时在详情里挑。
