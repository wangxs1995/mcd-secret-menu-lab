**正文**

你们平时吃麦当劳是不是也偷偷干过这些事：薯条蘸圆筒、把圆筒扣进可乐、鸡块夹进双吉……

最近发现一个开源小项目「麦门隐藏菜单研究所」，把这些隐藏吃法做成了一套工具：

🧪 12 道隐藏吃法图鉴，原料全是门店真实在售的东西
✅ 能连上麦当劳官方 MCP，告诉你附近这家店今天哪几道能做（早餐吃法只在早餐时段有，它真的会提醒你）
💰 价格直接走麦当劳实时算价，热量按官方营养表累加
📋 每一道都能生成一张「机密档案」配方卡，截图就能发（我配图就是它生成的）
🛒 确认之后还能一键下单

我最喜欢的三道：
1️⃣ 冰雪薯条 —— 薯条 + 圆筒，¥18.5，咸甜永动机
2️⃣ 可乐浮雪 —— 可乐 + 圆筒，¥14.5，五块钱复刻麦乐酷
3️⃣ 勇者鸡块 —— 鸡块蘸草莓新地，地狱难度，敢试的来评论区报到

不装任何东西也能玩：它有个在线页面，点「🎲 今天吃什么？随机来一道」就行。

项目在 GitHub 搜 mcd-secret-menu-lab（作者 wangwengao），开源免费，还能投稿你自己的隐藏吃法 👀

## 版本 B · 技术向：「我用麦当劳 MCP 做了个隐藏菜单生成器」

**标题备选**
- 麦当劳居然开放了 MCP，我拿它做了个隐藏吃法生成器
- 零依赖 Node 写的麦当劳隐藏菜单工具，开源了
- 程序员节参赛作品：把麦当劳菜单玩成实验室

**正文**

麦当劳中国开放了官方 MCP（35 个工具：菜单、营养、算价、下单、活动日历……），正好赶上程序员节的创意开发大赛，我做了个有点好玩的东西：

「麦门隐藏菜单研究所」——用真实在售餐品组合「隐藏吃法」，自动校验门店能不能做、算价格算热量、生成配方卡、一键下单。

几个我自己觉得有意思的点：
🔧 零依赖 Node，自己写了个 Streamable HTTP 的 MCP 客户端
🧩 麦当劳 MCP 的返回不是纯 JSON，是「说明文字 + JSON」混合文本，营养表还是个紧凑文本表格，专门写了解析器
🕗 用 reservationDate 可以拉到早餐时段菜单，所以早餐吃法能正确识别
🎪 会读活动日历，推荐时顺带告诉你当前在搞什么活动
📷 配方卡是 HTML 渲染 + 无头浏览器截图，纯静态演示页零安装可玩

离线也能跑：样例数据是从 MCP 拉下来的真实快照（183 个餐品 + 158 项营养），不是手写的。

仓库：GitHub 搜 mcd-secret-menu-lab。欢迎 star、欢迎投稿你的隐藏吃法。
